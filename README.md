# SAUCE_DEMO_APPLICATION-TESTCASE

SAUCE_DEMO_APPLICATION-TESTCASE is a Software Testing project created to validate the functionality and end-to-end business flow of the SauceDemo web application.
The application is tested from Login → Products → Sorting → Cart → Checkout → Order Confirmation → Logout, covering both positive and negative scenarios. The test cases verify important UI elements, navigation, product selection, cart operations, checkout validations, price calculations, order completion, and session/logout functionality.
